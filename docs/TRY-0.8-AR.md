# تجربة RasmCAD 0.8-dev

فك ضغط حزمة التشغيل ثم افتح `RasmCAD-Advanced.html` باستخدام Edge أو Chrome.
لا تحتاج إلى Python أو Node.js لتشغيله. هذه نسخة تطوير، وحفظ DWG الحقيقي غير متاح.

من GitHub: افتح فرع `codex/command-depth` ثم Code → Download ZIP. فك الضغط
وشغّل `restore-release.cmd`، أو استخدم حزمة التشغيل الجاهزة على Drive.

- النسخ: حدّد عنصراً،اكتب COPY،ثم حدّد نقطة الأساس. اكتب `ARRAY 4 FIT`
  وحدّد مكان آخر نسخة. العدد يشمل الأصل. `U` للتراجع وEnter لإنهاء الأمر.
- مطابقة الخصائص: اكتب MATCHPROP،اختر المصدر،ثم `SETTINGS` لاختيار الخصائص.
  طبّقها على عدة عناصر. الأمر لا يغيّر شكل العنصر أو نوع البعد.
- الدوران/التكبير: ROTATE أو SCALE،اختر نقطة الأساس،ثم `REFERENCE`،وأدخل
  الزاوية/الطول الأصلي ثم القيمة الجديدة. يمكن أيضاً تحديد المرجع بالنقاط.
- الطباعة: Plot / Print،اختر الورقة والمقياس والمنطقة. `Pick plot window`
  يسمح بتحديد زاويتين بالماوس. اختر PDF أو Browser printer. راجع المعاينة؛
  الطباعة بالمقياس الصحيح تحتاج Actual size / 100% وتعطيل ترويسة المتصفح.
- الحفظ: Save As يتيح اسم الملف ونوعه ومكانه إذا دعم المتصفح ذلك.
  المشروع `.rasm.json` يحفظ بيانات البرنامج كاملة. ملفات DXF متاحة بأربعة
  إصدارات للتبادل مع CAD،مع فقد بعض خصائص التحرير الأصلية للبلوكات والتهشير والأبعاد.
- الأبعاد: DIMSTYLE يسمح بتغيير الحجم والمقياس والألوان والدقة ووزن الخط.
  `DIMCONTINUE AUTO` و`DIMBASELINE AUTO` يكرران الأبعاد؛`U` يتراجع عن آخر بعد.

الأوامر التي تحتاج عناصر تبدأ بالتحديد ثم Enter،أو بتحديد العناصر قبل تشغيل
الأمر. اتبع نص الطلب أسفل الرسم؛Enter وEsc يحافظان على الأجزاء التي اكتمل رسمها.
التشغيل على جهازك وEdge والطابعة الفعلية يحتاج تجربة منك؛لم يتم تغيير سياسات الحماية.
