    Command reference

    Choose a command below. The drawing prompt shows the options available at the current step. Enter confirms a value or ends a repeated command; Esc keeps completed edits.

    Commands have different selection and point stages. Only the options named in the active prompt are accepted. This reference describes implemented workflows.
    RasmCAD Advanced 0.9-dev

    Drawing and commands

    Choose a tool and follow the green command prompt: it names the next point or value needed. Coordinates use 100,200, relative offsets use @50,0, and relative distance/angle uses @100<45. Angles are in degrees, counterclockwise from the positive X axis. For a line, pick the start point, move the cursor to set the direction, type a length such as 100, and press Enter to commit that segment. Press Enter again, right-click, or use Finish to end connected lines. A circle finishes after a radius point or a positive numeric radius. You can also press, drag and release to create a single line, circle or rectangle; a line drawn in one stroke ends automatically. Stop, Esc or Select discards only the unconfirmed preview: a line endpoint or circle radius must be clicked, entered as a value, or completed by releasing a drawing stroke before it becomes a permanent object. Completed objects remain. The object count tracks committed drawing objects; a preview is shown separately.

    TaskCommandWorkflow
    Line / polylineL / PLPick successive points, or aim the cursor and enter a length. Finish / Enter / right-click or double-click ends the command. U removes the last segment/vertex; C closes the path.
    Rectangle / circleREC / CRectangle: opposite corners. Circle: center then radius; D chooses diameter after the center. Enter 2P or 3P before picking for diameter endpoints or three circumference points.
    Arc / textA / TArc: CENTER uses center/start/end direction; 3P uses three circumference points. Text: insertion point, then type the text.
    Move / copyM / COSelect objects, confirm, then pick base and destination points. COPY supports Single/Multiple, Array/Fit, and U. MOVE supports Displacement.
    Rotate / scaleRO / SCSelect objects, choose a base point, then enter an angle or positive scale factor. R / Reference uses a known angle or length and a target value.
    Trim / extendTRIM / EXTENDFollow the prompt to identify a boundary and the line segment to modify.
    Offset / mirrorOFFSET / MIRROROffset creates a parallel copy at a distance; mirror uses a two-point reflection axis. Enter KEEP or DELETE before the axis to choose source handling.
    Fillet / chamferFILLET / CHAMFERUse two intersecting line objects with a radius or setback distance.
    ArraysARRAY / POLARARRAYSelect geometry, then enter the counts, spacing or rotation requested by the prompt.
    Explode / joinEXPLODE / JOINExplode separates supported composite geometry; dimension arrow outlines and primitive colors remain, but filled arrow areas are not independent fill objects. Join connects compatible line geometry.
    MeasurementsDISTANCE / ANGLE / AREAPick the requested points or supported geometry. Read the result in the command area.
    Aligned dimensionDIMPick two measurement points, then the position of the dimension line.
    View / historyZ / U / REDOFit the drawing / undo / redo. Wheel zooms; middle-button drag pans.

    Selection: clicks add objects by default. Shift+click removes an object; Ctrl+click adds it. Use the Selection menu to switch to Replace selection. Drag left to right to select objects entirely inside the window; drag right to left to select objects that cross the window. Start Move, Copy or another edit command, pick the objects when prompted, and press Enter to confirm the selection.

    Command line: start typing an English command to see suggestions. Tab fills the first match; arrow keys select a suggestion. Enter submits the typed value, or the suggestion explicitly selected with an arrow key. Up/Down recall earlier input when suggestions are closed. Command history keeps previous inputs and results. Repeat starts the last tool again. Select returns to object picking. Diagnostics downloads a report when troubleshooting an unexpected result.

    Properties: select objects, change the fields you need, and click Apply changed properties. ByLayer inherits the layer color. Fields you do not change stay intact for each object in a mixed selection.

    Dimension styles: select a dimension and set text height, overall scale, arrow size/style, extension-line offset/extension, text gap, precision, prefix/suffix, and separate line/text colors. Inherit object color follows the dimension object color, including its ByLayer setting; uncheck it for an explicit line or text color. Without custom defaults, new dimensions start with a readable text height calculated from the current zoom, stored in drawing units. In Text / dimension override, <> inserts the measured value: for example L=<> mm. Overall scale changes annotation appearance, not the measured value. Use as dimension defaults applies these settings to dimensions you draw afterward; Apply changed properties edits the selected dimensions.

    Shortcuts: Ctrl+S save project · Ctrl+O open · Ctrl+N new · Ctrl+Z undo · Ctrl+Y redo · Delete erase · Enter/right-click finish · Esc cancel · F1 help. Drawing toggles appear in the status bar.

    Advanced 2D: expand Advanced 2D in the left tools or type a command. STRETCH takes two crossing-window corners, then base/destination. BREAK takes two cut points on a selected object. LENGTHEN, ALIGN, PEDIT and SPLINEDIT show operation forms. SPLINE creates an editable interpolating curve. HATCH takes selected closed boundaries or a picked interior, with SOLID/ANSI31/CROSS patterns; HATCHEDIT changes its settings. REGION creates planar polygonal regions. BLOCK and INSERT retain reusable definitions; BEDIT/REFEDIT stage edits until BCLOSE SAVE or CANCEL. ATTDEF manages definitions and ATTEDIT instance values. WBLOCK exports a native block project. DIMSTYLE manages named rendered styles; DIMCONTINUE, DIMBASELINE, DIMORDINATE, DIMEDIT and MLEADER extend annotations. OSNAPSET enables intersection, perpendicular, tangent and nearest modes. Perpendicular and tangent require a first/base point.

    Vector PDF: Plot vector PDF opens paper, orientation, drawing-unit, scale 1:N and plot-window settings. The PDF contains vector geometry and embedded substitute-font text. Print that PDF at Actual size / 100% to preserve the selected scale. Source SHX fonts and complex text shaping may differ.

    New workflows: SELECT FENCE / WPOLYGON / CPOLYGON, QSELECT and SELECTPREVIOUS improve selection. PLINE accepts A for a three-point arc, L for straight segments and WIDTH start,end. DIMASSOC links a selected dimension to a selected line or circle; STATUS and REMOVE inspect or detach it. PLOT includes saved page setups, scaled layout viewports and multi-sheet PDF. RECOVERY is optional local browser storage.

    Files and layers: Open reads supported DWG and ASCII/binary DXF locally. DWG-based DWT/DWS templates, BAK and SV$ backups are recognized by their file contents. After import, Continue drawing closes the report. The active drawing layer is visible and unlocked; source layer states are preserved. Use Layers → Unlock visible layers to edit objects on deliberately locked source layers; Undo restores their locks. Export DXF downloads supported editable geometry for CAD exchange. Save project downloads a native .rasm.json file; optional local recovery is available through Recovery. Save As also offers experimental DWG2000 exchange with geometry readback; polylines, blocks, hatches and dimensions export as visible independent geometry. Keep a native project for full editability. Keep the downloaded project to continue editing. Review import notices for unsupported content. A file's release label and its underlying DWG/DXF format version are separate.

    An independent 2D CAD application. Full visual fidelity across all AutoCAD formats is not established. DWF/DWFx, DGN, advanced entities, imported paper-space layouts and 3D workflows are not supported as complete systems. RasmCAD plot layouts support multiple scaled viewports and batch PDF. Managed-device security policies still apply.
